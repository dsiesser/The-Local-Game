# The Local Game v5

- Gross score auto-advances to the next golfer for a single digit 2–9; scores 10+ remain editable and save on blur.
- Larger icon-based six-tab navigation.
- Handicap index entry from -10.0 to 99.9.
- Up to 24 golfers, six physical foursomes, with device-local group selection.
- Pigeon games selected via horizontal tabs at the top of the Pigeon page.
- Presses show which player/team is up, or All square.

Upload the extracted files to the GitHub repository root and commit. Existing Supabase tables and Netlify environment variables remain unchanged.
